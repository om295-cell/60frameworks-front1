# 60frameworks-front1

Production-ready, premium experiential-marketing & creative-agency frontend application built with **React + Vite + TypeScript**.

## 🚀 Features
- **Design System**: Brand tokens with Plus Jakarta Sans editorial typography.
- **11 Homepage Sections**:
  1. Sticky Header & Navigation with Mobile Drawer
  2. Hero with Cinematic Backdrop & Dual CTAs
  3. About Us with Animated Milestone Statistics
  4. Services with 6 Bespoke Capability Cards
  5. Trusted Clients with Monochrome Wordmarks & Orange Accents
  6. Industry Sectors with Interactive Vertical Switcher
  7. Case Studies with Filterable Tabs & Project Modal
  8. Why Us with 4 Strategic Pillars & Execution Badges
  9. Testimonials with Impact Metric Badges & Orange Accents
  10. Final CTA with High-Contrast White Action Button
  11. Footer with Navigation, Service Directory & Contacts
- **Interactive Modals**: Contact Inquiry Form with validation & Case Study Inspector.
- **Performance & Vercel Ready**: Preconfigured with `vercel.json`, code-splitting, and sub-73kB gzipped initial load.
- **Zero-Downtime Resilience**: Seamless in-memory fallback datasets when backend is disconnected.

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel
1. Link this repository in Vercel.
2. Framework Preset: **Vite**.
3. (Optional) Set `VITE_API_BASE_URL` to your production API endpoint.
4. Deploy!
